Aktivasi Layanan Webhook

Masukkan token dari owner beserta Universe ID dan Roblox API Key game kamu untuk mengaktifkan webhook realtime.

Token dikirim oleh Owner setelah pembayaran dikonfirmasi.
Dapat dilihat di Creator Dashboard → Experiences → Universe ID.
API Key dengan izin read & write DataStores.
Login Admin / Member

Panduan Pengisian

Siapkan data-data ini dari Roblox Creator Dashboard:

  1. Universe IDBuka Creator Dashboard Roblox → pilih Experience kamu → salin Universe ID (bukan Place ID).
  2. API KeyMasuk ke Open Cloud → Create API Key → Berikan izin datastores:read dan datastores:write pada Universe kamu.
  3. Token AktivasiMasukkan kode token unik yang diberikan oleh owner (Rafly).
