Pertanyaan Umum (FAQ)

Apakah lisensi ini benar-benar permanen seumur hidup? ▼
Ya, paket Lifetime hanya perlu dibayar satu kali (Rp 450.000). Anda tidak akan pernah ditagih biaya bulanan atau perpanjangan apapun di masa mendatang.
Bagaimana cara menemukan Roblox Universe ID? ▼
Buka Creator Dashboard Roblox (create.roblox.com) → pilih tab Experiences → klik ikon titik tiga pada game kamu → pilih Copy Universe ID.
Apakah didukung untuk banyak platform (Saweria, BagiBagi, SociaBuzz)? ▼
Ya! Server gateway kami telah mendukung multi-platform secara otomatis sehingga bisa menerima webhook dari Saweria, BagiBagi, maupun SociaBuzz.
