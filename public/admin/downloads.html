📖 Panduan Pemasangan di Roblox Studio

  1. Buka Roblox Studio & Enable HTTP Requests
    Buka game kamu → Klik Game Settings → Pilih tab Security → Aktifkan toggle Allow HTTP Requests dan Enable Studio Access to API Services.
  2. Import Model .rbxm
    Klik kanan pada Workspace atau ServerScriptService di Explorer → Pilih Insert from File... → Pilih file Saweria_V2_Roblox_Model.rbxm yang telah diunduh.
  3. Atur Group & Permissions
    Pindahkan folder UI ke StarterGui, dan Script Server ke ServerScriptService sesuai instruksi di dalam model.
  4. Uji Coba dengan Simulator
    Jalankan game di Studio (Play Mode) lalu buka tab Simulator Donasi di dashboard admin ini untuk mengirim donasi uji coba secara live!
