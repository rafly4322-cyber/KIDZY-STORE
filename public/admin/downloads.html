📖 Panduan Pemasangan di Roblox Studio

1

Enable HTTP Requests & API Services

Buka game kamu di Roblox Studio → Klik Game Settings → Tab Security → Aktifkan toggle Allow HTTP Requests dan Enable Studio Access to API Services.

2

Import Model .rbxm

Klik kanan pada ServerScriptService di Explorer Roblox Studio → Pilih Insert from File... → Pilih file model Saweria_V2_Roblox_Model.rbxm yang telah diunduh.

3

Uji Coba dengan Simulator

Jalankan game di Studio (Play Mode), lalu buka tab Simulator Donasi di dashboard admin ini untuk mengirim donasi uji coba live!
