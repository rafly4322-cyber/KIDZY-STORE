📖 Panduan Menghubungkan Suara Rekordbox 7 ke Roblox

1
Install VB-Audio Virtual Cable (Gratis)

Download dan pasang VB-CABLE Driver di Windows. Ini bertindak sebagai kabel audio virtual antara Rekordbox 7 dan Roblox.

2
Atur Output di Rekordbox 7

Buka Rekordbox 7 → Preferences (Gerigi) → Audio. Pada bagian Master Output, pilih CABLE Input (VB-Audio Virtual Cable).

3
Atur Input Mic di Roblox

Di Roblox Player → Settings → Voice Chat / Microphone, pilih CABLE Output (VB-Audio Virtual Cable). Pastikan Voice Chat aktif!

4
Jalankan Watcher Otomatis (Opsional)

Jalankan perintah node rekordbox_watcher.js di terminal untuk mendeteksi lagu secara otomatis saat diputar di Rekordbox 7.
