Aktivasi Layanan Webhook

Masukkan token lisensi kamu beserta Universe ID game Roblox untuk mengaktifkan webhook realtime secara instan.

Token diberikan oleh Admin setelah pembayaran dikonfirmasi.
Universe ID dapat dilihat di Creator Dashboard Roblox → Experiences.

Panduan Aktivasi

Langkah mudah mengaktifkan gateway donasi Roblox kamu:

1

Salin Universe ID

Buka Creator Dashboard Roblox → Experiences → Salin Universe ID.

2

Dapatkan Webhook

Setelah aktivasi berhasil, URL Webhook unik kamu akan langsung muncul.

3

Pasang di Game

Tempel URL di platform Saweria dan uji coba donasi live di game.
