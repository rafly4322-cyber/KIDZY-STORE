Instant Activation Live Webhook Gateway

Aktivasi Layanan Webhook

Masukkan kode token lisensi kamu beserta Universe ID game Roblox untuk mengaktifkan webhook donasi realtime secara instan.

Token diberikan oleh Admin setelah konfirmasi pembayaran di Discord.
Ditemukan di Roblox Creator Dashboard → Experiences → Copy Universe ID.

Panduan 3 Langkah

Langkah mudah mengaktifkan gateway donasi Roblox kamu:

1

Salin Universe ID

Buka Creator Dashboard → Experiences → Salin Universe ID map kamu.

2

Dapatkan Webhook URL

Setelah aktivasi selesai, URL Webhook unik kamu akan langsung terbit di layar ini.

3

Hubungkan ke Saweria

Tempel URL Webhook di dashboard Saweria/BagiBagi kamu dan sistem siap menerima donasi!
